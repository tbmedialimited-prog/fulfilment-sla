CONFIRMED BY DPD (Andy Smith, 2026-05-26):
  - Login: POST https://api.dpdlocal.co.uk/user/?action=login (Basic auth) -> geoSession
  - Track: POST https://api.customers.dpd.co.uk/v1/customer/parcel/tracking
    with GEOSession header, body has one of 4 search params:
      * parcelNumbers: [...]            <- we use this
      * customerReference + postcode
      * customerReference
      * searchKey
  - The *XXXXX suffix in track URLs is meaningless internal noise - ignore it
  - Webhooks would disable customer notifications, so we're staying with polling

Changes from v15:
  - lib/dpd.ts: rewritten to use api.customers.dpd.co.uk endpoint
    Added trackDpdBulk() for batch tracking lookups (more efficient)
  - /api/dpd-debug: tests all 4 search parameter combinations
    so we can verify which return data for parcels created via Mintsoft
